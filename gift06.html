01

はじめに：なぜあなたの診断結果は「まだ半分」しか威力を発揮していないのか？

「強み発掘メーカー」をご利用いただき、誠にありがとうございます。まずは無事に診断を終えられたことを心より歓迎いたします。

しかし、コンテンツビジネスの現場視点から、一つ重要な事実をお伝えしなければなりません。診断ツールで出力された結果は、3つの選択肢をもとに導き出された「全体の10%程度の表面的なデータ（＝入り口の言葉）」に過ぎません。

多くの発信者は、この診断結果をそのままSNSやブログに貼り付けて満足してしまいます。しかしそれでは、他の診断者と同じような「どこかで見たことのある浅い発言」にとどまり、読者の心を動かすことはできません。

診断結果の本質とは、あなたの中に眠る「原石の場所」を示した宝の地図です。宝を掘り当て、他者には絶対に真似できない「唯一無二の価値・強み」へと磨き上げるためには、高精度AI（ChatGPT / Claude）を活用した【言語化の深掘り・構造化プロセス】が不可欠となります。

本プロンプト集は、実戦的なプロンプトエンジニアリング技術を注入し、あなたの「弱みと錯覚していた経験」や「曖昧な診断結果」を、読者を引きずり込む「熱狂的なコンテンツ」や「高単価な商品」へと極限まで進化させるために設計されています。

02

診断結果・完全覚醒のための「4ステップ・ワークフロー」

ステップ実行アクション得られる成果物・効果
Step 1「強み発掘メーカー」で診断を実施し、結果全文をコピーする潜在的な強み・葛藤データの抽出
Step 2目的に応じたプロンプト（①〜⑤）を選択するnote・X・商品化・逆転ストーリー・LPなど最適な出口の決定
Step 3プロンプト内の [診断結果] にコピーした文章を貼り付けてAIに送信するプロレベルの高度な長文原稿・構成案の一括生成
Step 4出力された文章に「あなただけの1行の実体験」を肉付けするオリジナルコンテンツの完成・収益化への直結
03

プロンプト①：診断結果を「2,500字超・熱狂を呼ぶ1本のnote記事」に育成するプロンプト

診断結果を単なる解説文ではなく、読者が思わず夜中に読みふけってしまうような、ストーリーテリング型の長文note記事へ爆発的に拡大・進化させます。

PROMPT CODE 01

PROMPT
# 依頼
あなたはコンテンツマーケティング、ストーリーテリング、および人間心理学のプロフェッショナルライターです。
以下の[診断結果]のデータを多角的に解剖し、読者の感情を激しく揺さぶり、共感と行動を巻き起こす長文note記事の本文を作成してください。

# 診断結果
[ここに強み発掘メーカーの診断結果を貼り付けてください]

# 執筆の厳格な指示
1. 【導入部：暗闇からの共感】
   診断結果に含まれる「悩み・感情・葛藤」を抽出し、読者自身が「まさに今の自分のことだ」と錯覚するような、具体的で生々しい情景描写（時間、場所、周囲の音、胸の苦しさなど）から始めてください。
2. 【中盤：コペルニクス的転換（逆転のパラダイムシフト）】
   なぜその経験やコンプレックスが「致命的な弱み」ではなく、「誰も真似できない唯一無二の強み」なのかを、心理学的・論理的な視点から解き明かしてください。診断結果の言葉を10倍の深さで補強してください。
3. 【実践編：小さな1歩の提示】
   同じ闇の中で悩んでいる読者に向けて、明日から（あるいは今日今すぐ）実行できる具体的かつ負荷の低い「小さなアクションステップ」を1つだけ提案してください。
4. 【文体・トーン＆マナー】
   ・基本は「です・ます調」ですが、時に熱っぽく、時に静かに語りかけるようなメリハリのある文章構成にしてください。
   ・「〜を享受する」「〜の功罪」といった論文のような堅苦しい専門用語は極力排除し、エモーショナルで血の通った会話調・独白調を維持してください。
5. 【視覚的リズムと構造化】
   ・適度に小見出し（###）を挟み、重要箇所は太字（**文字**）で強調してください。
   ・要点には箇条書きを活用し、スマホの流し読みでも強烈なインプレッションが残るレイアウトにしてください。
6. 【エンディング：余韻と問いかけ】
   最後は一脈の希望を残しつつ、読者の心に深く刺さる深い問いかけで締めくくってください（例：「あなたもずっと、その優しさを隠して生きてきませんでしたか？」）。

# 文字数・ボリューム
2,500字〜3,500字程度の重厚で読み応えのある長文で出力してください。

08

プロンプトの効果を120%引き出す「運用テクニック」

⚡ プロンプト使いこなしの3大極意

  • 【極意1】AIの出力結果に「自分の生の体験談」を1行だけ注入する
    AIが書き出した長文の中に、あなただけにしか語れない「具体的なエピソード（例：会社帰りの電車で泣いたこと、あの時言われたショックな一言）」を1〜2行だけ付け加えてください。それだけでAI特有の無機質な文章が消え去り、人間味のあふれる神原稿に昇華します。
  • 【極意2】ChatGPTとClaudeを使い分ける
    論理的で構造化された構成案（プロンプト③）やSNS投稿（プロンプト②）には「ChatGPT」、エモーショナルで情緒的な長文note（プロンプト①や④）には「Claude」を使うと、驚くほど高品質な文章が得られます。
  • 【極意3】診断結果のパラメーターを変えて何度も生成する
    「強み発掘メーカー」で別の選択肢を選び、異なる診断結果が出た際も本プロンプト集をご活用ください。複数の診断結果を組み合わせることで、あなたの中に眠る多面的な強みをいくつも掘り起こすことが可能です。
09

おわりに：発信の第一歩を踏み出したあなたへ

ここまでお読みいただき、本当にありがとうございました。

自分の「強み」や「経験」は、自分自身では当たり前すぎてなかなか気づけないものです。しかし、このプロンプト集を使えば、あなたの内部にある葛藤やストーリーが、誰かを救う「輝くコンテンツ」へと生まれ変わります。

まずはプロンプト①〜⑤の中から、今のあなたが一番ワクワクするものを選び、AIに診断結果を投げかけてみてください。画面の向こうに出力される「あなただけの素晴らしい文章」に、きっと驚くはずです。

あなたの素晴らしい発信が、一人でも多くの読者に届くことを心より応援しております。
