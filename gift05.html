【本ドキュメントの目的】

このたびは「強み発掘メーカー」をご紹介いただき、誠にありがとうございます。

このドキュメントは、「強み発掘メーカー」で導き出した診断結果をベースに、実際にBrainやnoteで“売れる商品”（テーマ・ペルソナ・コンセプト・タイトル・価格設定）へと具体的に昇華させるための【商品プロデュース専用プロンプトエンジニアリング集】です。

01

はじめに：なぜ「自分の強み」が分かっても、商品が作れないのか？

「強み発掘メーカーを使って、自分の潜在的な強みや発信の軸は見えた。……だけど、ここからどうやって有料記事やBrainの商品に変えていけばいいんだろう？」

このような壁にぶつかる方は少なくありません。強みを知ることと、それを「人がお金を払ってでも買いたい商品」に変換することの間には、マーケティング的な【構造化プロセス】が必要だからです。

売れるコンテンツを作るためには、単に知識や体験を書き出すのではなく、以下の要素を緻密に組み上げる必要があります。

  • 市場の需要（マネタイズテーマ）： 誰のどんな痛みを解決するのか？
  • ペルソナの言語化（心理描写）： どんな深夜の悩みに寄り添うのか？
  • ポジション＆タイトル（オファー）： 思わずクリックしてしまう魅力的な商品名は？
  • 適切な価格戦略（バリュープライシング）： 内容量とターゲットに合わせた価格帯は？

本ドキュメントに収録された3つのプロンプトを順番に実行（Step 1 → Step 2 → Step 3）するだけで、AI（ChatGPT / Claude）があなたの優秀な「専属コンテンツプロデューサー」となり、膨大な市場データをもとに上記すべての要素を自動で弾き出してくれます。

02

失敗しない商品化ワークフロー（4ステップ）

ステップ実行アクション得られる成果物・効果
Step 1「強み発掘メーカー」で診断を実施し、結果全文をコピーする潜在的な強み・葛藤データの抽出
Step 2【プロンプト①】を実行し、売れる「商品テーマ」を確定させる実績ゼロでも勝てる3つの商品企画案と決定軸
Step 3【プロンプト②】を実行し、「ターゲット（ペルソナ）」を深掘りする検索窓に入力する本音・刺さるキャッチコピー5選
Step 4【プロンプト③】を実行し、「タイトル・価格・構成」を決定する即出品可能な5つのタイトル案と、松竹梅の価格戦略
03

プロンプト①：診断結果から「勝てる商品テーマ」を策定する

あなたの診断結果を解剖し、市場の悩みと合致するコンテンツの「テーマ・切り口」を3つ抽出し、その中で最もマネタイズしやすい決定打を理由付きで提案させます。

PROMPT CODE 01

PROMPT
# 依頼
あなたはデジタルコンテンツ販売およびBrain/noteのトッププロデューサーです。
以下の[診断結果]をもとに、実績ゼロや後発組の立場でも十分に需要があり、実際に有料（Brain/note）で販売できる商品テーマ案を提案してください。

# 診断結果
[ここに強み発掘メーカーの診断結果を貼り付けてください]

# 出力・提案してほしいこと
1. 【商品テーマ案（3選）】
   この診断結果の経験・強みから作成可能な商品テーマを3つ提案してください。それぞれのテーマについて、「誰の、どのような具体的悩みを解決するか」を明記してください。
2. 【ポジショニングと勝算】
   上記3つのテーマそれぞれについて、なぜそのテーマに需要が存在するのか、市場の背景や顧客心理の観点から解説してください。
3. 【後発組向けの決定打（1選）】
   提案した3つのテーマの中で、「実績ゼロ・後発組」の立場から参入しても、強力な既存競合に埋もれず最も差別化しやすい（勝ちやすい）テーマを1つ厳選し、その理由を客観的に提示してください。

💡 AI出力の実例イメージ（プロンプト①実行時）

・提案テーマ1： 「婚活50回挫折から学んだ、自己肯定感を下げずに良縁を引き寄せる感情コントロール術」

・提案テーマ2： 「実績ゼロ・スキルなしから始める、最初の1円を稼ぐためのThreads×note超実践ロードマップ」

・後発組向けの決定打： テーマ2。理由：「大きな実績」を売る既存層に対し、「直近で0→1を達成した再現性」の方が初心者に響きやすいため。

04

プロンプト②：ターゲット（ペルソナ）の心理を限界まで具体化する

決まったテーマに対して、商品を買う顧客が「どのような感情で悩んでいるか」を限界まで深掘りします。深夜に1人で検索する「泥臭い本音の言葉」をあぶり出すことで、心に突き刺さるコンテンツが作れるようになります。

PROMPT CODE 02

PROMPT
# 依頼
あなたは行動心理学およびダイレクトレスポンスマーケティング（DRM）に精通した消費者心理の専門家です。
以下の[診断結果]と[商品テーマ]をもとに、この商品を最も必要としているターゲット（ペルソナ）の深層心理を鮮明に描いてください。

# 診断結果
[ここに強み発掘メーカーの診断結果を貼り付けてください]

# 商品テーマ
[プロンプト①で決まったテーマを貼り付けてください]

# 描いてほしいこと
1. 【深夜の検索ワード（5選）】
   ターゲットが夜、布団の中で一人スマホを見ながら、検索窓やX/SNSの検索欄に思わず打ち込んでしまう「泥臭い本音のキーワード・感情の吐露」を5つ挙げてください。
2. 【無料情報で解決できなかった真の原因（3選）】
   ターゲットがこれまでYouTubeや無料ブログ等の情報を見ても悩みを解決できなかった根底の原因（思考の罠やノウハウコレクター化の原因）を3つ挙げてください。
3. 【刺さるフックコピー（3選）】
   タイムライン上でこの記事を見かけたターゲットが、「まさに自分のために書かれた文章だ」と直感して手を止めるキャッチコピー案を3つ提案してください。

💡 AI出力の実例イメージ（プロンプト②実行時）

・深夜の検索ワード： 「副業 才能なし」「Threads ノウハウ通りやっても伸びない」「発信ネタがない 絶望」

・無料情報で解決できない理由： 抽象的な精神論ばかりで「今日の最初の1歩」の行動手順が書かれていないから。

・刺さるフックコピー： 『「私には何もない」とスマホを閉じたあなたへ。実績ゼロのまま1本目の記事を売る逆転のコンテンツ戦略』

05

プロンプト③：売れる「商品タイトル」と「価格戦略」を決定する

ターゲットが明確になったら、最後に「商品タイトル」と「価格設定（松竹梅）」を弾き出します。実績ゼロを逆手に取った共感型タイトルの作り方や、コンテンツ量に応じた値付けの根拠まで提示させます。

以下の情報をもとに、実際に市場で売れる商品タイトル案と、商品の価値を最大化する価格設計案を提案してください。

# 診断結果
[ここに強み発掘メーカーの診断結果を貼り付けてください]

# 商品テーマ・ターゲット像
[プロンプト①および②で出力された内容を貼り付けてください]

# 提案してほしいこと
1. 【魅力的な商品タイトル案（5選）】
   ターゲットのベネフィット、数字、具体性、または逆説的フックを取り入れた商品タイトル案を5つ提案してください。
2. 【後発組向け・共感特化タイトル（1選）】
   5つのうち、「実績ゼロ・後発組」という弱みを強みに変え、読者の強い共感を生み出すベストタイトルを1つ厳選し、選定理由を解説してください。
3. 【松竹梅の価格戦略と推奨ボリューム】
   商品の完成度やボリューム（文字数・特典の有無）に応じた3パターン（例：お試し版100円〜500円／標準版980円〜1,980円／完全版2,980円〜4,980円）の価格帯を提示し、それぞれの価格帯で盛り込むべきコンテンツの内容量を提案してください。

💡 AI出力の実例イメージ（プロンプト③実行時）

・共感特化タイトル： 『【実績ゼロ・後発組専用】「何もない」を価値に変える。ポチポチ選ぶだけで商品が完成する強み発掘マネタイズ』

・価格戦略例：

- 【100円〜500円】：文字数3,000字（概念＋手順の解説のみ）

- 【1,980円】：文字数8,000字（実践プロンプト集＋具体的な事例付き）

- 【3,980円】：文字数15,000字（プロンプト集＋購入者限定サポート・動画解説付き）

06

プロンプト成果を最大化する「3つの実践テクニック」

⚡ AI回答の精度を跳ね上げる極意

  • 【テクニック1】① → ② → ③ の一貫実行（対話型セッション）
    3つのプロンプトは、ChatGPTやClaudeの「同じチャットルーム内」で順番に送信してください。AIが前文のコンテキスト（文脈）を保持したまま思考するため、テーマから価格決定までブレのない一貫した商品企画が完成します。
  • 【テクニック2】フィードバックによる「追加指示」を活用する
    1回目の出力で違和感がある場合は、諦めずに「もっと初心者向けにして」「感情的な言葉を増やして」「ビジネス系ではなく恋愛系のトーンにして」と具体的に追加指示を出してください。対話を重ねるごとに精度が格段に上がります。
  • 【テクニック3】診断結果のバリエーションで複数商品を量産する
    「強み発掘メーカー」で異なる選択肢を選んで診断をやり直すことで、1人の人間の中に眠る別の切り口（例：「仕事の悩み」「対人関係の悩み」「時間管理の悩み」など）から、2本目・3本目の有料商品を量産することが可能です。
07

おわりに：あなたの商品が、誰かの未来を変える

このプロンプト集を使えば、あなたの中にある小さな経験や挫折、乗り越えてきた日常が、誰かの深い悩みを解決する「素晴らしい価値」へと生まれ変わります。

あなたのコンテンツが、多くの読者に届くことを心より応援しております。
