01

はじめに

コンテンツを販売する際、「何を書いて告知すればいいかわからない」「売り込み感が強くなって読者に敬遠されてしまう」と悩むことはありませんか？

本プロンプト集は、note・Brain・Tips・ココナラなどで作成したWebコンテンツを、AI（ChatGPT、Claudeなど）を活用して効果的なSNS告知文へと変換するための実践型プロンプト＆出力実例集です。

AIに任せきりにするのではなく、「AIでベースとなる高品質な文章（8割）を作成し、最後にあなた自身の生の実体験や言葉（2割）を加える」ことで、読者の心に深く刺さる投稿を爆速で作成できます。

02

本プロンプト集の活用手順（ステップ・バイ・ステップ）

  1. 販売商品情報の整理： 販売するコンテンツのターゲット、価格、解決できる悩み、実績データ等を簡単に書き出します。
  2. 告知目的（フェーズ）の選定： 「販売前・認知拡大」「販売直後・実績アピール」「中身の提示」「値上げ前の駆け込み」など、現在のフェーズに合わせたパターンを選択します。
  3. プロンプトのコピペ： 対象パターンの「コピペ用プロンプト」をAIにそのまま貼り付けます。
  4. 【 】箇所の書き換え： 【 】で囲まれた部分にご自身の最新商品情報を入力します。
  5. 手直し（温度感の追加）： 出力された案の中から最適なものを選び、ご自身の「生の実体験」や「口調」を1〜2行付け加えて投稿します。
03

① 共感型｜「これ、私のことかも」と思ってもらうパターン

【活用シーン】 販売前〜発売直後。売り込み感を抑え、ターゲットが日々抱えている悩みやモヤモヤに寄り添い、商品を自分ごと化させたいときに使います。

PROMPT
あなたはコンテンツ販売に詳しいSNSマーケターです。
以下の商品情報をもとに、X（旧Twitter）向けの「共感型」告知文を3案作成してください。

【商品名】：【例：初心者向けCanvaデザイン攻略教材】
【ターゲット】：【例：デザインに苦手意識がある副業初心者】
【ターゲットが抱えている悩み】：【例：時間をかけてもダサいアイキャッチしか作れず発信に自信が持てない】
【商品で得られる変化】：【例：テンプレ活用で10分でプロ級の画像が作れるようになる】
【自分自身の体験・失敗・気づき】：【例：昔は1枚の画像に3時間かけて挫折しかけた】

【作成条件】：
・冒頭1〜2行でターゲットが「これ、私のことかも」と感じるフックを作る
・読者の悩みや感情を具体的に言語化し、売り込み感を強くしない
・自分の体験や気づきを自然に入れ、共感と親近感を生む
・最後は商品紹介へ自然につなげる（押し売りしない）
・Xで読みやすいように1行ごとに適度な改行と空白行を入れる
・3案はそれぞれ切り口（失敗談重視 / 悩み共感重視 / ビフォーアフター重視）を変える

💡 AI出力実例（切り口：失敗談重視のケース）

デザインセンスがゼロすぎて、画像1枚作るのに3時間かかっていた頃の話をします。

「色使いがダサい…」「文字の配置が変…」と悩み、投稿を作るだけで夜が明ける毎日。

正解が分からず、副業自体を諦めかけたこともありました。

でも、センスじゃなくて「型」を知らなかっただけなんです。

かつての私と同じようにデザインで躓いている人のために、誰でも10分でプロ級画像が作れる「Canva攻略テンプレ」をまとめました。

デザインの悩みから解放されたい方はぜひ覗いてみてください👇

✨ 仕上げのワンポイント： 「自分も同じことで悩んでいた」という個人的な失敗談や感情を1つ追加することで、文章に一気に温度感が宿り、信頼性が急上昇します。

04

② 実績・検証型｜「実際にやった人」の信頼を作るパターン

【活用シーン】 販売中〜販売後。販売数、反応、実験結果などの具体的なデータを見せ、商品の確実性と社会的証明（UGC）を高めたいときに使います。

PROMPT
あなたはデータ重視の実績派SNSマーケターです。
以下の実績・検証データをもとに、X向けの「実績・検証型」告知文を3案作成してください。

【商品名】：【例：X集客完全自動化ロードマップ】
【販売価格】：【例：1,980円】
【販売数】：【例：24時間で100部完売】
【販売期間】：【例：リリース1日目】
【SNSでの反応】：【例：Brainランキング1位獲得、口コミ30件以上】
【実際に試したこと】：【例：予約投稿と自動導線構築を3ヶ月テストした結果】
【わかったこと・学び】：【例：毎日手動でポストするより導線設計が全てだった】
【商品で提供している内容】：【例：自動化構築の全5ステップ動画解説】

【作成条件】：
・数字や具体的な事実を冒頭に配置し、インパクトを作る
・単なる自慢に見えないよう「なぜそうなったのか」という読者に役立つ学びを入れる
・実際に試して検証したリアルなプロセスと再現性をアピールする
・最後は商品紹介へ自然につなげる
・Xで読みやすいように1行ごとに適度な改行と空白行を入れる
・3案は（数字インパクト重視 / 作業効率化重視 / 読者の再現性重視）で変化をつける

05

③ チラ見せ型｜「中身を少し見せて」読みたくさせるパターン

【活用シーン】 販売全般。商品の中身やノウハウの一部（図解、テンプレ、具体例）を先行公開し、「もっと詳しく知りたい！」という期待感を醸成します。

PROMPT
あなたはコンテンツの魅力を伝える専門ライターです。
以下の商品情報をもとに、X向けの「チラ見せ型」告知文を3案作成してください。

【商品名】：【例：ライティングの成約率を3倍にするPASONA法則実践書】
【ターゲット】：【例：記事を書いても最後まで読まれないブロガー】
【解決する悩み】：【例：読者が途中で離脱してしまい購入に至らない】
【本編で紹介している重要ポイント】：【例：PASONA法則の『O（Option）』の書き方】
【無料で見せてもよい具体例・ノウハウ】：【例：商品概要を書く際の実践フレーズ3選】
【購入するとさらに得られる内容】：【例：成約率を跳ね上げる残り4ステップと添削事例】

【作成条件】：
・本編の価値が伝わる具体的な一部分を1つ開示する
・無料投稿単体だけでも読者に「勉強になった」と思わせる有料級の内容にする
・「ただし、これだけでは不十分で〇〇が必要」と本編への余白（続きが読みたい心理）を残す
・冒頭1〜2行で強烈に興味を引くフレーズを入れる
・最後は自然に商品紹介へつなげる
・Xで読みやすいように改行を入れる
・3案は（テンプレ公開 / 失敗回避テク公開 / チェックリスト提示）で作成する

💡 AI出力実例（切り口：テンプレートの一部公開例）

セールス文で商品を紹介するとき、ただ「機能」を書いていませんか？

成約率が高い人が使っている基本テンプレートを1つだけ公開します。

×「この講座ではマーケティングが学べます」

〇「この講座を受けると、SNS集客の迷いが消え、来月には最初の1件が成約します」

違いは『商品』ではなく『変化した未来』を伝えていること。

本編では、この成約率を3倍に跳ね上げる残り4つのライティング型を全て解説しています👇

06

④ 限定・値上げ型｜「今買う理由」を伝えるパターン

【活用シーン】 販売部数の上限、販売期限、価格変更など、後回しにしがちな購入検討層の背中を自然に押し、「今買うべき理由」を作りたいときに使います。

PROMPT
あなたは行動心理学に詳しいSNSプロモーションの専門家です。
以下の商品情報をもとに、X向けの「限定・値上げ型」告知文を3案作成してください。

【商品名】：【例：Instagram運用完全ロードマップ】
【現在の価格】：【例：980円（特別価格）】
【次の価格】：【例：4,980円（通常価格）】
【現在の販売数】：【例：47部】
【限定部数・販売期限】：【例：残り3部完売、または本日23:59まで】
【価格変更の理由】：【例：コンテンツ加筆およびサポート体制拡充のため】
【おすすめしたい人】：【例：今年こそインスタ運用を本格化させたい人】
【購入すると得られること】：【例：最安値で永久アクセス権と今後のアップデート教材を獲得できる】

【作成条件】：
・限定条件や価格変更のタイミングを明確に伝える
・煽りすぎず、事実と理由をわかりやすく開示する
・「今買う理由」が自然に伝わる比較（最安値の機会）を入れる
・不必要に不安を煽る表現は使わない
・最後に商品ページへの自然な導線を入れる
・Xで読みやすいように改行を入れる
・3案は（カウントダウン重視 / 透明性重視 / 最後のメッセージ重視）で作成する

💡 AI出力実例（切り口：値上げ理由を明記した透明性重視の例）

【お知らせ】Instagram運用ロードマップですが、本日23:59をもって初期価格（980円）での販売を終了します。

明日以降は加筆アップデートに伴い、通常価格（4,980円）に改定いたします。

早期に購入してくださった方を優遇するため、過去最安値での追加販売はありません。

「いつかインスタ運用を始めたい」と考えていた方は、最安値で手に入る最後の機会にぜひご活用ください👇

[商品リンク]

✨ 仕上げのワンポイント： 単に「値上げします」と言うだけでなく、「なぜ価格が変わるのか（コンテンツの追記・サポート追加など）」の納得できる理由を伝えると、誠実さが伝わり成約率が高まります。

07

4つの告知パターンの使い分けマトリクス

告知パターンおすすめのタイミングプロモーションの主目的
① 共感型販売前・認知を広げたいとき潜在的な悩みの掘り起こし、自分ごと化
② 実績・検証型販売後・数字や反応が出てきたとき社会的証明（信頼感）の提示、安心感醸成
③ チラ見せ型商品の中身を伝えて興味を高めたいとき価値の先行体験、本編への期待感醸成
④ 限定・値上げ型販売終了・値上げ前など締め切り直前「今買う理由」の提示、後回し防止・刈り取り
08

投稿前のセルフチェックシート（全6項目）

AIで生成した文章を調整し、実際のSNSに投稿する直前に確認すべき6つの必須チェックポイントです。

AIのスピード × あなたの生の体験＝最強の告知文

AIは、告知文を作る時間を短縮してくれる強力な相棒です。

ただし、AIが作った文章だけでは、あなた自身のリアルな経験や熱量までは伝わりません。

最後に「自分が実際に経験したこと」「読者に本当に伝えたいこと」を1つ加えてみてください。

それだけで文章の温度・信頼感は大きく変わります。

まずは4つのパターンのうち、今の販売フェーズに合うものを1つ選んで、さっそく投稿を作ってみましょう！
